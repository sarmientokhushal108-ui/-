# Flora Personal OS

一个基于 Next.js 的中文个人操作系统 Dashboard，用于集中管理客户、项目、销售复盘、雅思学习、金融学习和穿搭内容管理。

## 功能模块

- **客户管理**：客户线索、跟进记录、成交阶段、下一步行动。
- **项目管理**：项目、里程碑、任务、截止日期、进度同步。
- **销售复盘**：赢单原因、流失原因、异议处理、销售话术沉淀。
- **雅思学习**：听说读写计划、练习任务、薄弱项复盘。
- **金融学习**：财经新闻、金融概念、行业案例和知识卡片。
- **穿搭内容管理**：选题、脚本、素材、剪辑、发布排期和数据表现。

## 本地运行

```bash
npm install
npm run dev
```

然后打开 <http://localhost:3000/>。

## 在 Codex 中开发

本项目不需要 Vercel，可以直接在 Codex 工作区中编辑、运行和预览。具体的启动、端口预览、构建检查和日常开发方式见 [CODEX.md](CODEX.md)。
